DSH Desktop v1.1.0 — 使用说明
==============================

【首次使用：先安装 DSH 运行环境】（一次性，约 1~2 分钟）

  本应用需要 DSH（DeepSeek Harness）提供后台服务。

  1. 安装 Node.js 18 或更高版本（推荐 LTS）：
     https://nodejs.org
     安装时保持默认选项即可。

  2. 打开 命令提示符(cmd) 或 PowerShell，执行：
     npm install -g @deepseek-ai/dsh

  3. 装完后双击运行本应用即可（应用会自动启动 DSH 服务）。

【运行】

  解压后进入 "DSH Desktop" 文件夹，双击 DSH Desktop.exe。
  应用会自动拉起后台服务并打开界面，无需手动开终端。
  托盘图标可最小化/退出；退出应用时会自动关掉它拉起的服务。

【常见问题】

  · Windows 弹出 SmartScreen"已保护你的电脑"提示？
    这是未签名应用的正常现象：点"更多信息" → "仍要运行"。

  · 打开后提示"需要先安装 DSH 运行环境"？
    按上面的第一步安装 Node 和 dsh，然后点页面上的"重试连接"。

  · 想换端口？
    默认连接 http://127.0.0.1:3080，可在启动前设置环境变量 DSH_URL。

【卸载】

  直接删除整个解压文件夹即可（不写注册表、不留残留）。

【依赖与许可】

  · 本应用基于 Electron 构建。
  · 后台服务为 MIT 许可的 npm 包 @deepseek-ai/dsh。
